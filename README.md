# 🏥 Hospital Management System (HMS)

**Project Link:**https://hospital-management-system-cn66.onrender.com

## 📌 Project Overview

A comprehensive Hospital Management System developed using Python and Django to simplify hospital operations and improve patient care management.

The application provides separate modules for Admin, Doctor, Patient, and Receptionist to manage hospital activities, appointments, prescriptions, billing, and patient records efficiently.

## 🎯 Key Features

### 1. Admin Module
- Admin login and authentication
- Manage doctors and patients
- Manage receptionist accounts
- Monitor appointments
- Manage hospital records
- Dashboard overview

### 2. Doctor Module
- Doctor login
- View assigned appointments
- Manage appointment details
- Create and update prescriptions
- View patient medical records
- Manage consultation details

### 3. Patient Module
- Patient registration and login
- Update personal information
- Book doctor appointments
- View appointment history
- View prescriptions
- Access billing details

### 4. Receptionist Module
- Patient registration
- Manage patient details
- Book appointments
- Manage doctor schedules
- Handle billing information

### 5. Appointment Management
- Online appointment booking
- Doctor availability management
- Appointment scheduling
- Appointment status tracking
- Appointment history

### 6. Prescription Management
- Create prescriptions
- Update medical details
- View prescription history
- Manage patient treatment records

### 7. Billing Management
- Generate patient bills
- Manage billing details
- Track payment information
- View billing history

## 🚀 Installation and Setup

### Step 1: Clone Repository

```bash
git clone https://github.com/Abdulrahman012345/HMS.git
```

### Step 2: Navigate to Project

```bash
cd HMS
```

### Step 3: Create Virtual Environment

```bash
python -m venv .venv
```

### Step 4: Activate Virtual Environment

Windows:

```bash
.venv\Scripts\activate
```

### Step 5: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 6: Configure Database

Configure your MySQL database credentials in the Django settings or environment variables.

### Step 7: Apply Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### Step 8: Create Superuser

```bash
python manage.py createsuperuser
```

### Step 9: Run Development Server

```bash
python manage.py runserver
```

### Step 10: Open Application

```text
http://127.0.0.1:8000/
```
